# 学盟社小小萌建模

**三维版本已撤回，当前没有通过造型验收的模型交付。**

此前发布的三维模型在脸型、五官、发束、服装轮廓、布褶和鞋型上与设定图存在明显差异，不符合还原要求。GLB、FBX、Blend、交付 ZIP、预览器及对应错误截图已从当前 `main` 版本撤回。文件可读取、导出校验通过不代表角色造型合格。

- [小小萌角色设定图](assets/xiaoxiaomeng-character-model-sheet.png)
- [不合格项与后续造型验收要求](MODELING_REVIEW.md)

后续只有真实三维模型的正、侧、背视图与参考设计达到一致，才可恢复交付。不得以提高面数、调整灯光或生成新的二维效果图替代造型修正。
